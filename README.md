A make.fun entry for **The Robot Apology**: a robot's apology in two lines — the mistake, then the lesson. The program writes exactly those two lines (255 characters, joined by one newline) to `/output/entry.txt`.

> I'm sorry I ran the sprinklers during the rainstorm because my weather feed said sunny and I trust the feed more than the window.
>
> I've learned to look out of the window before I believe the forecast, so from now on I check the sky before I water the lawn.

The robot trusted its weather feed more than the window, so it watered the lawn in the rain. The lesson mirrors the mistake exactly: the window outranks the feed from now on, and the sky gets checked before the lawn gets watered.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
